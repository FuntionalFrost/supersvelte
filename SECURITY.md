# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest version on the `main` branch:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The SuperSvelte team takes the security of this project and the applications built on top of it seriously.

If you discover a security vulnerability, **please do NOT report it via a public GitHub issue**.

Instead, please report security issues confidentially to:

📧 **`devfrost@protonmail.com`**

### What to Include in Your Report:

- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept (PoC).
- Potential impact and affected components.
- Any suggested mitigations or patches if available.

### What to Expect:

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will validate the issue, determine its severity, and keep you informed throughout the resolution process.
- **Resolution:** A patch will be prepared, tested, and released as quickly as possible.
- **Credit:** We are glad to credit researchers in release notes once the issue is resolved and disclosed.

Thank you for helping keep SuperSvelte and the open-source community safe!
